# Example: Prompt Enhancement

## User Input (Vague)
> "Make a landing page for my movie platform called 'CineNova'. Use dark colors and purple. It should have a place for movie posters and a hero section."

---

## Enhanced Prompt (Stitch-Optimized)
**Overall Purpose**: A high-end, cinematic landing page for 'CineNova', a movie discovery and community platform. The vibe is premium, immersive, and visually striking.

**DESIGN SYSTEM (REQUIRED):**
- **Primary Color**: Electric Violet (#ba9eff) for vibrant CTAs and active states.
- **Secondary Color**: Deep Charcoal (#0a0a0a) for background and text containers to create depth.
- **Typography**: Display/Headlines in 'Manrope' for a bold editorial feel; Body in 'Inter' for high legibility.
- **Style**: Asymmetrical layouts, glassmorphism overlays, soft ambient glows instead of sharp shadows. Dark mode by default.

**PAGE STRUCTURE:**
1. **Header**: Glassmorphic navigation with CineNova logo (left) and subtle text links for "Explore", "Clubs", "Awards" (center), and Profile Icon (right).
2. **Hero Section**: Edge-to-edge cinematic background image overlaid with a gradient fade. Massive bold headline: "Your Next Cinematic Obsession Starts Here." Primary violet CTA: "Get Started".
3. **Poster Grid**: A dynamic, asymmetrical bento grid showcasing movie posters without hard borders.
    - **Highlight Posters**: Use labels like "Must Watch". Hover should scale the graphic beautifully.
4. **Community Section**: Split layout discussing the platform's community pulse, metrics (e.g. "12M+ Reviews"), and a high-quality abstract camera visual.
5. **Footer**: Minimalist dark footer with legal links and subtle iconography.

---
💡 **Tip**: Notice how the enhanced prompt adds specific hex codes, defines the typography "vibe" and font pairings, and breaks the page into a logical numbered structure. This provides Stitch with much clearer instructions.
